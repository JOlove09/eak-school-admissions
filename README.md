# EAK International School – Admissions Landing Page

## Project Overview

A modern, responsive, frontend-only admissions landing page for the fictional EAK International School, developed for the academic session 2027–28.

This project was developed as part of the EAK Pustak Pvt. Ltd. frontend hiring assignment.

The website helps parents explore academic programs, facilities, admission procedures, fees, and other important information through a user-friendly interface.

## Technologies Used

- React.js – Component-based user interface
- Vite – Development server and production build tooling
- JavaScript (ES6+) – Application functionality
- HTML5 – Semantic page structure
- CSS3 – Styling and responsive layouts
- Lucide React – Icons
- Git & GitHub – Version control and source-code hosting

## Features

- Responsive navigation bar
- Admissions hero section with calls to action
- Six school differentiators
- Four academic programs
- School highlights and statistics
- Facilities image gallery
- Five-step admission process
- Important admission dates
- Required documents checklist
- Fee structure table
- Parent testimonials
- Interactive FAQ accordion
- Final admissions call to action
- Admission enquiry form
- Campus visit request form
- Frontend form validation and confirmation messages

## Installation and Setup

### Prerequisites

- Node.js and npm
- VS Code or another code editor

### Run Locally

1. Clone or download the repository.
2. Open a terminal inside the project folder.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.

### Production Build

`npm run build`

### Preview Production Build

`npm run preview`

### Code Quality Check

`npm run lint`

## Project Structure

- `public/images/` – Local images
- `src/components/` – Reusable navigation component
- `src/sections/` – Individual landing page sections
- `src/styles/` – CSS stylesheets
- `src/App.jsx` – Main application structure
- `src/main.jsx` – React entry point

## Important Notes

- This is a frontend-only demonstration website.
- No backend, database, authentication, or API integration is required.
- Form submissions display local confirmation messages but do not save or transmit information.
- School statistics, fee details, dates, and testimonials are illustrative.
- The school is fictional, and campus imagery is illustrative rather than a representation of a real institution.

## Project Objective

To provide a clear, accessible, responsive admission experience that informs parents, builds trust, answers common questions, and encourages admission enquiries.
